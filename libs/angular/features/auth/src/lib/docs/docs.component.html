Getting Started

kod3.dev is a browser-based IDE built with Angular, React, NestJS and Monaco Editor inside an Nx monorepo. You can use it in two ways:

Sign in with GitHub

Clone any of your repositories (public or private), edit files, use git operations, and chat with the AI assistant. Full read/write access.

Continue as Guest

Explore a read-only demo of this IDE's own source code. Browse files, read code, try the editor, and chat with the AI assistant - no account needed.

Cloning Repositories

After signing in with GitHub, you'll be prompted to enter a repository URL. Only GitHub repositories are supported. Each repository is cloned into its own isolated Docker container - your workspace is fully sandboxed and private to your session.

  • Public repos are cloned directly - no token needed.
  • Private repos require a GitHub OAuth token (scope: repo). The token is requested automatically when you sign in.
  • Your GitHub token is never stored in the cloned repository or persisted to disk.
  • Each workspace container includes git, Node.js, and a shell - you can install packages, run scripts, and use the integrated terminal.

Security

Your GitHub token is encrypted with AES-256-GCM before being stored in a Redis session. Sessions expire after 30 minutes of inactivity and the token is wiped on logout. The token is used at runtime only and is never committed to your repository.

  • Encryption key isolation: the AES key lives in a separate environment variable, not in Redis - compromising the cache alone reveals only ciphertext.
  • In-memory cache: Redis runs with persistence disabled (--save "" --appendonly no) so encrypted tokens never touch disk.
  • Network isolation: Redis is bound to an internal Docker network with no host port exposure and is protected by a password (requirepass).
  • Transport security: all browser traffic is served over HTTPS via the reverse proxy.

Code Editor

The editor is powered by Monaco Editor - the same engine behind VS Code - with support for 20+ programming languages.

  • Multi-tab editing with unsaved change indicators
  • Auto-save on content change
  • Syntax highlighting, IntelliSense, and code folding
  • Code formatting with Prettier on save
  • Side-by-side diff viewer for git changes
  • Tab context menu: Close, Close Others, Close to the Right, Close Saved, Close All

File Explorer

The sidebar file tree lets you browse, create, and manage files in your repository.

  • Tree view with expand/collapse folders
  • Context menu actions: New File, New Folder, Rename, Delete
  • File search via command palette (fuzzy search by filename)
  • Real-time file watching - changes on the server are reflected automatically

Git Integration

The Source Control panel in the activity bar gives you full git workflow capabilities. A badge on the icon shows the number of changed files.

Stage & Commit

Stage or unstage individual files, write a commit message, and commit. Discard changes to revert files.

Push & Pull

Push your commits to remote or pull the latest changes. See ahead/behind counts in real time.

Branches

Switch branches or create new ones via the branch picker in the status bar. Shows last commit info for each branch.

Stash

Stash your uncommitted changes, then pop or apply them later. Useful when switching branches.

Context menu on changed files: Stage, Unstage, Discard Changes, Open Changes (diff view).

Commit history: View past commits with hash, author, date, and the number of files changed. Git status updates in real time via WebSocket.

AI Assistant

The AI panel provides a chat interface powered by Groq running Llama 3.3 70B. Responses are streamed in real time.

Chat

Ask general programming questions or get help with your code.

Explain

Send the currently open file as context and ask the AI to explain it.

Modify

Request code changes - the AI returns suggestions that can be applied as a diff.

Shortcuts

Press Ctrl + Enter (or Cmd + Enter on Mac) to send a message.

Voice Control

Control the IDE hands-free using voice commands. Click the microphone button in the status bar to start recording, speak your command, then confirm or cancel. Voice transcription is powered by Whisper and intent parsing by Llama 3.3 via Groq.

File & directory creation

New files and directories are created relative to the currently active file's directory. If no file is open, they are created at the workspace root.

Terminal

The integrated terminal gives you direct shell access to your workspace container. It is powered by xterm.js and connects to the backend via WebSocket, providing a real PTY session inside your Docker workspace.

Multi-tab Sessions

Open up to 4 terminal tabs simultaneously. Switch between them, close individual tabs, or add new ones. Tab count is persisted across page reloads.

Resizable Panel

Drag the top edge of the terminal panel to resize it. The terminal automatically re-fits to the new dimensions and notifies the server to resize the PTY.

Theme Sync

The terminal theme updates instantly when you toggle between dark and light mode - no refresh required.

Shared Architecture

The terminal logic lives in a shared library (@org/shared/terminal) used by both Angular and React IDEs. Only the component wrappers are framework-specific.

How it works

When you open a terminal, the client creates an xterm.js instance and connects via Socket.IO. The server spawns a PTY process inside your Docker workspace container using docker exec. Input and output are streamed in real time. The terminal supports full ANSI escape sequences, colors, cursor movement, and interactive programs like vim and top.

Theme

Switch between dark and light mode using the theme toggle button in the bottom status bar. Your preference is saved in the browser and syncs automatically with the Monaco editor theme.

IDE Layout

The interface is divided into five main areas:

Activity Bar

Left-side icons for Explorer, Source Control (with change badge), AI Assistant, and Terminal. Click to toggle panels.

Sidebar

Resizable panel showing the active view. On mobile, it opens as a drawer overlay.

Editor

The main area with tabbed Monaco editor. Open multiple files and switch between them.

Terminal

Bottom panel with multi-tab terminal sessions. Resizable, with real PTY access to your Docker workspace.

Status Bar

Bottom bar showing current branch (clickable), username, guest badge, theme toggle, and logout.

The layout is fully responsive - on screens smaller than 768px, the sidebar collapses into a slide-out drawer with a backdrop overlay.

Architecture - Nx Monorepo

The project is structured as an Nx monorepo. Both Angular and React frontends share the same backend API, TypeScript contracts, utilities, and styles.

This architecture allows both frameworks to reuse the same TypeScript interfaces, DTOs, utility functions, and SCSS styles - while each framework maintains its own feature libraries, UI components, and state management.

Deployment - Docker Architecture

The application is deployed as a set of Docker containers orchestrated with Docker Compose. To ensure full security, each user gets their own dockerized sandbox environment - a completely isolated container with its own filesystem, shell, and processes. No other user can access your workspace, files, or terminal session.

NestJS API

Handles authentication, file operations, git commands, and terminal sessions. Runs as a Docker container with access to the Docker socket proxy.

Workspace Containers

Each user gets an isolated Debian container with git, Node.js, and a shell. The API uses docker exec to spawn PTY sessions for the terminal.

Docker Socket Proxy

The API never accesses the Docker socket directly. A proxy container restricts API access to only the required Docker endpoints.

Redis Sessions

User sessions and encrypted GitHub tokens are stored in Redis with automatic expiry. No sensitive data is written to disk.
